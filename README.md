# Kaggle-TPU-v5e-8-SGlang-Jax-Qwen3

This repository is for running **Qwen3 with SGLang + JAX** on **Kaggle free TPU v5e-8**.

## Goal

Make it easy to understand and reproduce a Kaggle-free-tier TPU v5e-8 run configuration for Qwen3 inference experiments.

## Kaggle Environment Target

- Platform: Kaggle Notebooks
- Hardware: TPU VM v5e-8 (free tier, when available)
- Runtime stack: JAX + SGLang + Qwen3 model assets

## Expected Outcome

Using this setup, you should be able to launch and validate a Qwen3 model run on Kaggle TPU v5e-8 and iterate on inference experiments from a notebook workflow.
